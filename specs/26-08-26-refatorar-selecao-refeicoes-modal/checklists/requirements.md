# Checklist de qualidade da especificação

- [x] O problema e o objetivo do fluxo estão descritos.
- [x] O código atual do modal e das superfícies relacionadas foi considerado.
- [x] As histórias estão priorizadas e são testáveis de forma independente.
- [x] Os cenários de aceitação cobrem seleção, prévia, inserção, salvamento e opções.
- [x] Os casos limite do fluxo principal estão registrados.
- [x] Os requisitos funcionais são verificáveis e não dependem de uma implementação específica.
- [x] O uso exclusivo de gramas está explícito.
- [x] Autosave, exportação e refatoração da escala estão explicitamente fora do escopo.
- [x] A decisão entre opções completas e substituição individual está registrada.
- [x] As entidades necessárias para suportar a reutilização estão descritas.
- [x] Os critérios de sucesso são mensuráveis.
- [x] Não há marcadores `[NEEDS CLARIFICATION]` pendentes.
